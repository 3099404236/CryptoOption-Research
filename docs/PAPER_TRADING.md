# 实时模拟盘（任务二）

**公网地址：<http://107.174.78.165:18090>**。页面只读，不需要登录，手机也能看，每 30 秒自动更新。

把第一阶段研究选出的策略，按事先写好的规则、用 **Deribit 实时公开行情**自动"交易"：
- 每一笔成交都按下单那一刻的真实买一 / 卖一价计算；
- 按 Deribit 费率扣手续费；
- 永续合约按真实的每小时资金费率记账；
- 期权在周五 08:00 UTC 按 Deribit 官方结算价现金结算。

这是**模拟交易**：不需要交易所账户，不用 API 密钥，也不下真实订单。2026-10-17 18:24 UTC（北京时间 10-18 02:24）开始运行，规则和参数运行期间不调整。

## 策略和交易时间

每个账户初始资金都是 100 万美元。

| 账户 | 规则 | 什么时候交易（UTC，北京时间 +8 小时） |
|---|---|---|
| `BTC_TSMOM28` | BTC 趋势跟踪：用前一天收盘价算过去 28 天涨跌，为正就做多 BTC 永续，否则空仓；仓位 = 40% ÷ 过去 30 天年化波动率，最多 2 倍净值 | 每天 00:05 调仓 |
| `ETH_TSMOM112` | ETH 趋势跟踪：112 天动量，规则同上 | 每天 00:05 调仓 |
| `BTC_CARRY` / `ETH_CARRY` | 资金费率套利：按指数价买现货、空等量永续（本金的 1/1.2，其余作保证金缓冲），收资金费 | 开始时建仓一次，之后每小时记资金费 |
| `BTC_STRADDLE_DH` | 卖 BTC 平值跨式（下周五到期），每条腿名义金额 = 净值（最多 25 BTC）；开仓后立即、之后每天 08:00 用永续把 Delta 调回 0 | 周五 09:00 开仓，周五 08:00 结算后平对冲 |
| `BTC_PUT30_HAR` | 卖 BTC 0.30 Delta 看跌（当周五到期），只在平值 IV ≥ 1.1 × HAR 预测波动率时卖；不对冲 | 周一 09:30 判断并开仓，周五 08:00 结算 |
| `ETH_STRANGLE25_HAR` | 卖 ETH 0.25 Delta 看涨和看跌各一份（当周五到期），过滤条件同上（最多 400 ETH） | 周一 09:30 判断并开仓，周五 08:00 结算 |
| `BTC_HOLD` / `ETH_HOLD` | 对照组：按指数价买入现货，一直持有 | 开始时买入一次 |
| 组合 | `BTC_STRADDLE_DH` + `BTC_PUT30_HAR` + `ETH_STRANGLE25_HAR` + `BTC_CARRY`，四份等额资金，第一阶段回测里最好的搭配 | — |

规则和参数都和第一阶段回测一致。HAR 预测用过去 1、7、30 天的已实现波动率（5 分钟收益）做回归，滚动用最近 365 天拟合，和 LEAN 回测里的定义相同。

## 成交和费用

| 品种 | 成交价 | 手续费 |
|---|---|---|
| 永续合约 | 买入按卖一价，卖出按买一价 | 0.05% × 成交金额 |
| 期权 | 买入按卖一价，卖出按买一价（币本位报价 × 指数价） | min(0.03% × 指数价, 12.5% × 权利金) × 张数 |
| 期权到期 | Deribit 官方结算价下的内在价值，现金结算 | min(0.015% × 结算价, 12.5% × 内在价值) × 张数 |
| 现货 | Deribit 指数价 | 0.10% |
| 资金费 | 每个整点按 Deribit 公布的该小时费率 × 指数价 × 持仓数量 | — |

## 怎么运行的

- 程序是 [`papertrade/papertrader.py`](../papertrade/papertrader.py)，只用 Python 标准库，在美国的一台 VPS 上以 systemd 服务的形式运行，开机自启，崩溃后自动重启。
- 程序分两个进程：
  - **交易进程**每 30 秒读一次 Deribit 公共行情，按规则交易，把账户、持仓、成交、净值、资金费存在 SQLite 里；然后导出一份只读快照（`state.json` 和几个 CSV）。重启后从数据库恢复，不会重复交易。
  - **网页进程**以无权限的临时用户运行，只能读这份快照：它只提供页面本身和固定的几个文件，不接触数据库，也没有任何写操作。
- 服务配置在 [`papertrade/systemd/`](../papertrade/systemd/)。

## 和真实交易的差别

- **没有盘口深度**：按最优买一 / 卖一价成交，默认这个价位能吃下整笔订单。期权单笔金额较大时，真实成交可能要吃掉几档。
- **检查频率**：每 30 秒检查一次，成交按检查那一刻的报价，不考虑排队和网络延迟。
- **资金费按整点小时计**：建仓那个小时按整小时算，有很小的误差。
- **现货腿**：资金费率套利和买入持有的现货按 Deribit 指数价、0.1% 手续费模拟，实际需要在现货交易所买入。
- **保证金**：按美元简化处理，没有模拟 Deribit 的组合保证金和强平。
- **周期太短**：几天到几周的结果只能用来展示流程，看不出策略好坏。判断策略要看第一阶段的多年回测。
- **卖期权账户不是每周都交易**：周一的两个账户只在隐含波动率明显高于预测时才开仓，很多周会选择不交易，这是规则本身。
